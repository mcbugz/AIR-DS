## Limitations (honest list)

- Tailwind extraction is static: functions, spreads, `require()`d presets and plugin-contributed theme values are skipped (listed above when hit).
- Contrast pairs are inferred from token NAMES, not from rendered usage; the report is an audit starting point, not WCAG evidence.
- `tier: "semantic"` is asserted, not known — raw palette scales are registered but not reclassified.
- Untyped (plain JS) components register with an empty prop list — the closed world covers the component NAME, not its props.
- Story-file detection is co-location-based (`<Name>.stories.*` next to the source); other story layouts are not found.
- The context bundle's prose skills/rules were designed for AIR-DS conventions — e.g. `llms.txt` says "Import everything from `@ds/react`" and references `--ds-*` naming, while THIS system imports from its own package and ships its own var names. The registries, closed-world data, and per-component docs are target-true; review the rule prose before shipping to agents (retrofit-aware prose is tracked as a @ds/context follow-up).
